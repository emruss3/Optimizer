## App vendors
- **TestFit** — deterministic rules solver, client-side, NOT ML (CEO: "good ole rules based engineering"); Zoneomics zoning as PAID ADD-ON used as pass/fail overlay + auto-filters, "Zoning input does not adjust the building when solving"; Site Solver ~$8k/yr. Complaints: glitches, weak on small irregular lots. https://www.testfit.io/integrations-zoneomics · https://support.testfit.io/knowledge/getting-started/zoning-profile · https://www.testfit.io/blog/2025-testfit-year-in-review · https://www.architectmagazine.com/technology/q-a-testfit-ceo-clifton-harness-has-some-reservations-about-his-successful-generative-design-tool_o · https://www.g2.com/products/testfit/reviews
- **Deepblocks** — own AI-digitized codes → PRECOMPUTED parcel-level buildable parameters; 16.4M+ sites, 700+ cities, new city <1 hr; generation is massing+pro-forma/HBU (no composed plans); from $18/mo. https://deepblocks.com/blog/category/about-us/the-evolution-of-zoning-data-extraction-navigating-nlp-and-llms/ · https://deepblocks.com/blog/other/2022-6-2-we-have-zoning-for-16430232-sites-in-the-us/
- **Archistar** — cloud generative massing in seconds, AI-ranked; own precomputed dataset (25k+ gov sources, AU-deep); US play = AI PreCheck permit review (Austin 5-yr, LA fire-rebuild). https://www.archistar.ai/blog/archistars-generative-design-engine/ · https://www.prnewswire.com/apac/news-releases/archistar-secures-contract-with-the-city-of-austin-for-groundbreaking-ai-powered-automated-building-permit-assessment-platform-302269544.html
- **Autodesk Forma** — ML surrogate analyses (noise/wind) + rule-based site automation; zoning USER-ENTERED, optional "3D Envelope by Zoneomics" extension (2024-08-19); $185/mo, free in AEC Collection. Complaints: area caps, regional context-coverage gaps. https://blogs.autodesk.com/forma/2024/08/19/autodesk-and-zoneomics-partner-to-bring-zoning-responsive-building-envelopes-to-forma/ · https://forums.autodesk.com/t5/forma-for-design-forum/forma-area-restriction/td-p/13253551
- **Giraffe** — user-driven parametric GIS sketching, live metrics; constraints modeled by users/apps over connected layers (Regrid parcels); Core $1k/user/yr. https://www.giraffe.build/real-estate-feasibility-software/ · https://www.globenewswire.com/en/news-release/2022/02/28/2393367/0/en/Giraffe-Launches-Site-Search-Powered-by-Regrid.html
- **Zenerate** — cloud generative (50k options) + pro-forma; constraints user-entered; AvalonBay enterprise partnership 2026-06-30. https://www.prnewswire.com/news-releases/zenerate-announces-partnership-with-avalonbay-communities-to-support-early-stage-multifamily-feasibility-analysis-302812861.html

## Data / rules vendors
- **Zoneomics** — ~20-25k US jurisdictions; per-district controls joined to parcels; AI extraction + certified-analyst verification; monthly updates; powers TestFit, Forma, Moody's, Redfin, Crexi, Regrid, Google. STF "see text field" → v2 conditional_control_values. https://www.zoneomics.com/product/api · https://blog.zoneomics.com/2025-recap-zoneomics-advancing-zoning-intelligence · https://commercialobserver.com/2026/06/inside-the-ai-revolution-quietly-reshaping-cres-slowest-data-layer/
- **Gridics** — the hybrid precedent: machine-readable code + patented calc engine (US10565665) → MATERIALIZED per-parcel envelope/density; ~10,000 parcels/hour batch; CodeHub pushes city amendments live → recompute; Cotality distribution 2025-10. https://gridics.com/zoning-data-api/ · https://patents.google.com/patent/US20200250775A1/en · https://gridics.com/codehub/
- **Symbium** — rules-as-code purist: regulations as logic programs (Epilog/Complaw), evaluated per request; instant permits in 271+ jurisdictions; no precomputed determinations. http://logicprogramming.stanford.edu/readings/symbium.pdf · https://symbium.com/instantpermitting
- **UpCodes** — code-text library (11M+ sections, 6k+ jurisdictions, ~7k updates/mo), amendment-tracked; strongest citation posture; no parcel layer. https://up.codes/ · https://www.prnewswire.com/news-releases/upcodes-launches-ai-native-specifications-solution-to-address-growing-compliance-complexity-in-us-construction-302729636.html
- **Regrid Standardized Zoning** — Zoneomics inside; 87M+ parcels, 6,400+ municipalities; 26 standardized fields; `zoning_data_date` vintage column; monthly refresh. https://regrid.com/zoning · https://support.regrid.com/parcel-data/zoning-schema
- **LightBox Zoning API** — top 50 MSAs, quarterly releases version-paired to parcel fabric. https://developer.lightboxre.com/apis/zoning
- **National Zoning Atlas** — human-coded per-district, ~9,000 jurisdictions, published methodology, no API yet; NSF LLM-automation research (zoning-gpt). https://www.zoningatlas.org/how · https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4476927 · https://github.com/National-Zoning-Atlas/zoning-gpt
- **Buildability** — LLM-per-request zoning interpretation with confidence scores; REST + MCP (`calculate_buildable_envelope`). https://buildability.us/api/
